# Tech Lead — фіксована база v1

Чотири збережені види персонажа для візуального затвердження, без нової генерації.

- `down.png`, `up.png`, `left.png`, `right.png`: по одному незмінному спрайту у прозорій клітинці 384×512.
- `source_*.png`: оригінальні збережені аркуші, з яких узято перший кадр.
- `manifest.json`: SHA-256 кожної бази та джерела, розміри, контури й координати опори.
- `verify.py`: перевірка, що бази не змінилися та кожен видимий піксель збігається з джерелом.
- `preview.png`: чотири види поруч у порядку down / up / left / right, без масштабування.

Це кадри з попередніх згенерованих аркушів спокою, не початковий аркуш, прикріплений користувачем. Від початкового вкладення в середовищі немає доступного PNG. Правий вид узято з останнього виправлення із закритим ротом.

Жодного зменшення, зміни палітри, перемальовування чи зміни пропорцій. Видалено тільки магентове тло через бінарну маску. Всі збережені видимі пікселі тотожні джерелу. Різні ракурси з попередньої генерації можуть мати відмінності дизайну — це потрібно оцінити під час затвердження бази.

Правило подальшої роботи: базові PNG не перезаписувати. Нові кадри зберігати в окремій папці; голову й незмінні частини брати безпосередньо з затвердженої бази. Нові пози кінцівок редагувати окремо. Перевіряти цілісність бази до та після побудови анімації командою `python verify.py`. Зміни самої бази робити лише як нову версію.
